# Fitness Pride

Официальный сайт школы обучения фитнесу Fitness Pride.

## Current milestone

- responsive site foundation;
- Fitness Pride brand system;
- desktop and mobile navigation;
- homepage hero using authentic school photography;
- Russian metadata and social preview.

The website is being built section by section from the approved content architecture.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Validation

```bash
npm run build
```

The original document and unprocessed media remain in the local project folder and are intentionally excluded from Git. Optimized assets used by the website live in `public/`.
